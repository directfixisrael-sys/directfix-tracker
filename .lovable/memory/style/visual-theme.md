---
name: Visual Theme - Apple Minimal
description: Clean Apple-like design with neutral grays, subtle shadows, no offset borders or glow effects
type: design
---
Apple-inspired minimal design system:
- Neutral gray palette (no warm/yellow tones) - pure grays with 0 saturation
- Subtle shadows (shadow-sm) instead of offset box-shadows
- Thin borders (border instead of border-2) with low opacity (border-border/60)
- Clean rounded corners (radius 0.875rem)
- No glow effects, no glassmorphism
- Buttons: shadow-sm, subtle hover darkening, active:scale-[0.98]
- Cards: shadow-sm, single thin border
- Inputs: rounded-xl, subtle focus ring with ring/30 opacity
- Font: Rubik, -apple-system fallback
- Primary color: 211 100% 50% (Apple blue)
